# Contest Scoring Method

Scores lie in predictable ways. This skill keeps blind multi-judge evaluations honest from seed scoring to final duel.

## Procedure

1. Score seeds to rank, never to crown. Seed scores systematically overestimate finished work — re-run every gate on the developed text before any final verdict.
2. Put full context in every judge prompt: object + function + desire + result. Causality and obedience cannot be scored from a closing line alone; context-free judging punishes missing context instead of weak ideas.
3. Compare within a batch only. Scores across judges or batches are not on the same scale — cross-validate batch leaders with a blind duel, never by raw number.
4. Label what was scored on every artifact (phrase-only vs full-script). Mixing the two metrics inflates or buries winners.
6. Apply hard disqualifiers before assigning any high score, never after. A seed that fails a structural gate (wrong material, broken causality, recycled core) must be capped or killed first — scoring potential first inflates seeds that collapse on development.
7. Prefer cascade specialists over a parallel jury for multi-stage work: one judge owns each dimension end-to-end (desire, image, physics) instead of every judge voting on everything. Juries average opinions; specialists preserve decisions across stages.

## Duel rules

- Blind prompts carry no author names, only texts.
- Judge each pair twice with order reversed; a vote that flips with order is discarded as position bias.
- Judges never vote on their own work.
- Winner = most duel wins; ties break by direct head-to-head, then by human decision.
