# Cloudflare Turnstile — Bypass Attempt Matrix

Tested against **camincargo.com** (aggressive Turnstile configuration).

## Result: ALL automated tools blocked

| Tool / Method | Result | Notes |
|---|---|---|
| `monolith` 2.10.1 | 403 Forbidden | Blocks at HTTP level |
| `cloudscraper` 1.2.71 | 403 Forbidden | Latest cloudscraper, default settings |
| `curl` with Chrome UA + cookies | Cloudflare challenge page only | Returns 5469 bytes of challenge HTML |
| `curl_cffi` 0.15.0 (impersonate=chrome124) | 403 Forbidden | TLS fingerprint impersonation not enough |
| Playwright Chromium headless + stealth init script | Stuck on challenge, never resolves | Detected as bot |

| **SingleFile browser extension** | **✓ Works** | Requires real browser with real user interaction |

## Why Turnstile is different

Cloudflare Turnstile is a **client-side JS challenge** that:

1. Detects headless browsers via:
   - Missing `navigator.webdriver` override detection (even when patched)
   - Screen/window dimension anomalies
   - Missing Chrome runtime features
   - Timing analysis of JS execution
   - Presence/absence of browser extensions
   - WebGL fingerprint
   - Canvas fingerprint

2. Never falls back to CAPTCHA — it silently fails for bots (shows "Verificando..." forever or redirects nowhere).

3. No HTTP-level bypass exists because the challenge token (`cf-turnstile-response`) is generated by JS execution in a real browser environment.

## Practical solutions

### Solution 1: SingleFile browser extension (recommended)

Install [SingleFile](https://chrome.google.com/webstore/detail/singlefile/mpiodijhokgodhhofbcjdecpffjipkle) in Chrome/Edge:

1. Open the target URL in your normal browser
2. Complete the Turnstile challenge (click "Verify you are human")
3. Click the SingleFile icon (📄) in the toolbar
4. Saves one `.html` file with ALL assets (CSS, images, fonts) embedded inline

Result: pixel-identical to the live page.

### Solution 2: DevTools → Copy outerHTML (partial)

If SingleFile isn't available:

1. Open page in browser, pass Turnstile
2. F12 → Console → `copy(document.documentElement.outerHTML)`
3. Paste into a file

**Limitation**: External CSS/images/fonts are NOT embedded. Page won't look the same offline.

### Solution 3: Save Page As → "Webpage, Complete" (browser default)

1. Ctrl+S → Format: "Webpage, Complete (*.htm, *.html)"
2. Saves .html + folder of assets

**Limitation**: Some dynamically loaded resources may be missed. Styling may differ slightly.

### Solution 4: Manual DevTools Save

1. Open page, pass Turnstile
2. Sources tab → find and save each CSS/JS file
3. Reassemble manually

**Only for simple pages or when nothing else works.**

## What NOT to waste time on

Do NOT attempt these for Cloudflare Turnstile sites — they will all fail:

- `wget --recursive` / httrack
- `monolith`
- `cloudscraper` / `curl_cffi`
- Playwright / Puppeteer headless (any browser)
- `undetected-chromedriver`
- Custom curl with any User-Agent
- Using cookies from a real browser in curl/requests (Turnstile token is per-session)

The ONLY reliable path is a real browser with human interaction + SingleFile or similar extension.
