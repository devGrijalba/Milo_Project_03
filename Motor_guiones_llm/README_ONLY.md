# MILO SCRIPT ENGINE 1.4.0 — SOLO MOTOR DE GUIONES

Este paquete contiene exclusivamente el motor de generación y validación de guiones de MILO.

Incluye:
- código del motor (`src/`)
- prompts narrativos (`prompts/`)
- banco optimizado de 1000 semillas (`data/seeds.json`)
- schemas y contratos
- configuración propia
- tests del motor
- documentación incluida originalmente en SCRIPT_ENGINE

No incluye motores de voz, imagen, subtítulos, efectos, canon global, artefactos globales ni workflows de producción audiovisual.
